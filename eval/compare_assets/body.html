Sections that ran out of reply room

A reply has a length limit (768 tokens, about 550 words). A model that is still reasoning when it hits the limit never writes its answer. Failed sections were asked again; any still unanswered count as "no answer", never as No.

Confidence: how sure each coder says it is

With every label, each coder states a confidence from 0 to 1. It is the model's own claim, not a measured probability. Qwen also has a token probability, P(Yes): its internal probability for the word "Yes" at the moment it writes the label.

Where the stated confidence falls

Number of answers in each confidence band.

Match with the final label, by stated confidence

How often the coder's label equals the final label within each band. A useful confidence matches more often in the higher bands.

Using confidence to choose sections for a person to check

If every answer stated below a cut-off (or with no confidence) went to a person, how many sections would they read and how many of the disagreements with the final label would they see?

Secondary: against the coders' first answers (before reconciliation)

A different question from the sections above: is a model as consistent with one human coder as a second human coder is? Each model takes one coder's seat and is scored against the other coder's first answer, before any reconciliation. These numbers are on a different scale from the final-label ones and are not compared with them.

Gray marker: the two coders' agreement with each other on these sections. Colored marker: the model in the second coder's seat. The difference and its 95% interval sit beside each pair.
