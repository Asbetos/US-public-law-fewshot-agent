Key measures

Classification rates

Each rate is shown with the counts it is computed from. Note the denominators: true and false positive are both over the number of actual positives, and true and false negative both over the number of actual negatives — so “false positive” here reads as false alarms per real positive, and “false negative” as misses per real negative. Neither is the textbook FPR/FNR.

Yes-class performance

Whiskers are 95% percentile bootstrap intervals over 2,000 row resamples. Q1 has far fewer positives, so its intervals are wider — that width is the finding.

Why accuracy is the wrong headline

A model that answers “No” to everything scores near-perfect accuracy on this data and zero on everything that matters. Compare like for like.

Measured, not estimated: every figure below is read back from the server's own logging, the GPU, the model on disk, and the per-row timings. On this hardware the infrastructure is the finding — a 27B model at 4-bit leaves barely 2 GiB for the KV cache, and that one number sets the throughput.
